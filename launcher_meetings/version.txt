<changelog>
<ru>
• В список значков можно добавить один эмодзи или до трёх обычных символов, например «LM». Несколько эмодзи, пробел внутри и четыре символа не принимаются.
• В наборе по умолчанию телефон заменён на сердце.
• Установщик спрашивает, ставить программу только для текущего пользователя или для всех. Для всех пользователей Windows запрашивает права администратора. По умолчанию установка идёт только для текущего пользователя.
</ru>
<de>
• Zur Symbolleiste lässt sich ein Emoji oder bis zu drei normale Zeichen hinzufügen, zum Beispiel „LM“. Mehrere Emojis, ein Leerzeichen darin und vier Zeichen werden nicht akzeptiert.
• Im Standardset wurde das Telefon durch ein Herz ersetzt.
• Der Installer fragt, ob das Programm nur für den aktuellen Benutzer oder für alle installiert werden soll. Für alle Benutzer fordert Windows Administratorrechte an. Standardmäßig erfolgt die Installation nur für den aktuellen Benutzer.
</de>
<en>
• You can add one emoji or up to three regular characters to the icon list, for example “LM”. Multiple emojis, a space inside, and four characters are not accepted.
• In the default set, the phone was replaced with a heart.
• The installer asks whether to install the program for the current user only or for everyone. Installing for everyone prompts Windows for administrator rights. By default, the install is for the current user only.
</en>
</changelog>
