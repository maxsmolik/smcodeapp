Urlaubstage-Planer

Vacation Planner · Планировщик отпуска

Годовой планировщик отпускных дней с тёмным интерфейсом: офлайн-праздники Германии по федеральным землям, баланс отпуска с переносом с прошлого года. Отметка дней одним нажатием, категории по долгому нажатию (работа, отпуск, Gleitzeit, праздник и свои). Локализация DE / RU / EN. Без аккаунта — данные только на устройстве.
